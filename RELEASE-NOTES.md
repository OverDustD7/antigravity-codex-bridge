# Codex Conversation Bridge 0.1.1 Windows preview

Use Antigravity to find existing Codex desktop chats, send work to them, and receive progress or final output in the originating Antigravity conversation. The ZIP includes the Antigravity plugin, the local Codex launcher and feedback script, and the optional Codex MCP server for contacting Antigravity.

Download the Windows ZIP from Assets, extract it, and follow the bilingual installation guide inside. The preview requires Node.js 24 or later and the two official desktop clients. The Antigravity CLI installs the bundled plugin.

The package passed strict Antigravity validation and isolated Windows tests for plugin installation, upgrade, removal, and message delivery. Full desktop setup in a fresh Windows account remains unverified. An optional Sidecar can resume idle-chat notifications after the application restarts. Ordinary background watches resume when their Antigravity conversation next runs.
